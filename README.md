# IGRA — Десятки и единицы

Игра для ребёнка: в руке появляются палочки, нужно их посчитать и ответить, сколько это десятков и единиц.
Потом палочки добавляются или забираются, и нужно посчитать снова.

- До 100 палочек, каждые 10 палочек связываются в десяток.
- Если палочек меньше 5, следующим всегда будет «+» на 7–10 палочек.
- Ответ кнопками (десятки и единицы) или голосом (Chrome, нужен интернет).

Игра — один файл `index.html`. Чтобы открыть её как сайт, включите GitHub Pages:
Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
